## 下载 JoyRead Plan

JoyRead Plan 支持 Windows、macOS 和 Linux 系统。选择适合你设备的安装包，即可开始整理阅读计划与笔记。

### 系统要求

| 系统 | 最低要求 |
|------|----------|
| Windows | Windows 10 (64-bit) |
| macOS | macOS 11.0+ |
| Linux | Ubuntu 20.04+ / Fedora 32+ |

### 下载链接

:::note[最新版本]
当前版本：v0.1.0 (开发中)
:::

前往 [GitHub Releases](https://github.com/joyreadplan/joyread-plan/releases) 下载最新版本。

### 安装说明

#### Windows
1. 下载 `.msi` 安装包
2. 双击运行安装程序
3. 按照向导完成安装

#### macOS
1. 下载 `.dmg` 文件
2. 拖动应用到 Applications 文件夹
3. 首次打开需要在系统偏好设置中允许运行

#### Linux
1. 下载 `.deb` 或 `.AppImage` 文件
2. 使用包管理器安装或直接运行

### 安装后建议

1. 打开设置页面，选择语言和主题
2. 如需自动补全书籍资料，可配置微信 API Key
3. 建议定期在设置中导出备份，妥善保存你的阅读数据
