## 常见问题

### JoyRead Plan 是免费的吗？

是的，JoyRead Plan 可以免费使用。

### 微信 API Key 有什么用途？

微信 API Key 用于获取书籍元数据，例如书名、作者、封面和简介等信息。它可以帮助你更快建立书库，减少手动填写内容。

### JoyRead Plan 会迁移其他阅读平台的数据吗？

当前重点是本地阅读计划、笔记和书籍资料管理。微信 API 配置仅用于查询书籍元数据，不用于迁移其他阅读平台的数据。

### 数据存储在哪里？

数据存储在本地 SQLite 数据库中，位于：
- Windows: `%APPDATA%/com.shawn.joyreadplan/`
- macOS: `~/Library/Application Support/com.shawn.joyreadplan/`
- Linux: `~/.local/share/com.shawn.joyreadplan/`

### 如何备份数据？

在设置页面点击「导出」按钮，选择保存位置即可创建备份文件。

### 支持哪些主题？

支持三种主题模式：
- 跟随系统
- 浅色模式
- 深色模式

### 如何切换语言？

在设置页面的语言选项中选择中文或英文即可。
