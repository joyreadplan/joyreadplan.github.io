## 核心功能

JoyRead Plan 把阅读计划、笔记沉淀、书籍资料和数据统计放在一个干净的桌面应用里，帮助你长期维护自己的阅读系统。

### 📚 阅读计划
- 为不同书籍创建独立阅读计划
- 设置每日或每周目标，安排更稳定的阅读节奏
- 记录当前进度，随时掌握剩余页数或章节
- 查看完成情况，让计划结束得更有仪式感

### 📝 读书笔记
- 使用 Markdown 编写摘录、评论和长篇思考
- 按书籍、章节与标签整理笔记
- 快速回看关键观点，减少灵感遗失
- 适合读后复盘、写作准备和知识整理

### 📊 数据统计
- 统计阅读进度、完成数量和计划状态
- 分析不同分类下的阅读分布
- 回顾阶段性阅读成果
- 用数据帮助你调整下一阶段的阅读方向

### 🔎 书籍元数据获取
- 通过微信 API 获取书籍元数据
- 自动补全书名、作者、封面等基础信息
- 减少手动录入，让建立书库更轻松
- API Key 仅用于书籍资料查询，不用于迁移其他阅读平台的数据

### 💾 本地数据管理
- 数据保存在本地设备中
- 支持导出备份，便于长期保存
- 结构清晰，适合维护个人阅读档案
- 未来可持续扩展更多数据管理能力

### 🎨 界面设计
- 温暖的琥珀色视觉风格
- 支持浅色、深色与跟随系统主题
- 中英文双语界面
- 面向桌面阅读场景优化的布局
