## 为什么选择 JoyRead Plan？

JoyRead Plan 专注于个人阅读管理：目标更清晰，笔记更容易沉淀，书籍信息也能通过微信 API 补全，适合长期、稳定地维护自己的阅读档案。

<CardGrid>
  <Card title="阅读计划管理" icon="open-book">
    为每本书设置节奏、期限与进度，让阅读目标从想法变成可执行的日常。
  </Card>
  <Card title="读书笔记" icon="pencil">
    使用 Markdown 记录摘录、感悟和章节线索，把零散想法整理成可回顾的知识资产。
  </Card>
  <Card title="微信 API 书籍元数据" icon="import">
    配置微信 API Key 后，可获取书名、作者、封面等书籍元数据，减少手动录入。
  </Card>
  <Card title="数据统计" icon="chart">
    用清晰的图表回顾阅读进度、完成情况和分类分布，发现自己的阅读习惯。
  </Card>
</CardGrid>
